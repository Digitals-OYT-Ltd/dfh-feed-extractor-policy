# Feed Article Collector privacy policy

Feed Article Collector is a private organizational Chrome extension whose single purpose is to
collect readable articles from a feed selected by the user and transfer the completed collection to
an application page selected by the user.

## Data handled

When the user starts a collection, the extension processes the feed URL and title, article URLs,
article titles and metadata, readable article text, collection timestamps, and collection errors.
This website content and browsing activity is used only to provide the extension's article-collection
and transfer features.

## Storage and retention

Active and most recently completed runs are stored locally in Chrome extension storage. An active
run is removed when it is cancelled or its collection tab is closed. A completed run remains until
the user selects **Delete saved run**, removes the extension, or completes another run that replaces
it. The configured application URL is stored locally until the user clears it or removes the
extension.

## Transfer and sharing

Completed article data is sent only to the HTTPS configuration page explicitly selected and
authorized by the user. The extension does not sell data, use it for advertising, or transfer it to
unrelated parties. The receiving application may retain imported content according to the
organization's policies.

## Security and user control

The extension accepts only HTTPS configuration pages and requests access only to the configured
site. Users can review or edit that URL, clear it to disable automatic transfer, download the latest
run, or delete locally retained completed-run data from the popup.

For privacy questions or requests concerning data imported into the receiving application, contact
the administrator who provided access to this private extension.

The use of information received through Chrome APIs adheres to the Chrome Web Store User Data
Policy, including the Limited Use requirements.
